# 代數式與公式星術訓練

只訓練公式和代入法的六級課堂遊戲：

1. 分辨代數式與公式，150 XP
2. 單一變數代入，含正數、負數、平方及分式，150 XP
3. 基礎雙變數代入，150 XP
4. 進階雙變數代入，含負數、括號及分式，150 XP
5. 利潤及薪金等生活情境公式，150 XP
6. 長方形及菱形圖形公式，先選公式再代入，150 XP

學生頁沿用「有理數混合運算複習」的三欄結構：角色在左、題目與數字鍵盤在中央、怪物與關卡地圖在右。答對獲得 15 XP並由左向右隨機施放六種星術之一，答錯扣除 10 XP並由巨龍向左反擊。連錯三題後啟動保護，之後答錯不再扣 XP，直至答對一題才恢復扣分規則。答錯後保留原題、顯示逐步解答，按「下一題」才繼續。

五張角色圖分別對應六個 Level，最後兩關共用最高階角色。學生可按 Level 查看個人作答統計及下載總體／錯題資料；登出與重置進度需要管理密碼。教師大屏顯示即時分 Level 統計、排行榜、支援提示和每班 300,000 HP 的混沌序列巨龍，並可下載全班總體數據及報表。

角色、巨龍和技能素材已轉為透明 WebP，數學式由本地 renderer 排版，不依賴外部數學套件，適合整班同時開啟。

## 本機預覽

```sh
python3 -m http.server 8080
```

教師大屏：`http://localhost:8080/dashboard.html`
