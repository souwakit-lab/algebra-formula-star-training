# 通項公式星術訓練

只訓練數列通項公式的五級課堂遊戲：

1. 直接代入一次通項求指定項，500 XP
2. 處理負號與負數結果，500 XP
3. 分數通項，分子分母同時代入並約至最簡，500 XP
4. 圓點圖案情境，根據已知通項求指定圖案，500 XP
5. 判斷指定數值是否為數列中的一項，500 XP

答對獲得 15 XP並隨機施放六種星術之一，答錯扣除 10 XP並觸發巨龍反擊。答錯後保留原題、顯示逐步解答，按「下一題」才繼續。

五張角色圖分別對應五個 Level。學生可按 Level 查看個人作答統計及下載總體／錯題資料；登出與重置進度需要管理密碼。教師大屏顯示即時分 Level 統計、排行榜、支援提示和每班 300,000 HP 的混沌序列巨龍，並可下載全班總體數據及報表。

角色、巨龍和技能素材已轉為透明 WebP，數學式由本地 renderer 排版，不依賴外部數學套件，適合整班同時開啟。

## 本機預覽

```sh
python3 -m http.server 8080
```

學生頁：`http://localhost:8080/`

教師大屏：`http://localhost:8080/dashboard.html`
